**یک سامانهٔ چند-تمپلیتی صفحهٔ اشتراک برای 3X-UI، PasarGuard و Rebecca.** ۳۰ طرح قابل انتخاب همراه پروژه عرضه می‌شود.
هر کدام را انتخاب کنید، نتیجه یک فایل HTML مستقل است که در اختیار شماست، و مشترک شما سرویس
شما را می‌بیند — نه ما را.

[نصب](/fa/installation/) · [دیدن تمپلیت‌ها](/fa/templates/)

## چیست

Gold-Template صفحهٔ اشتراک داخلی پنل را با یکی از ۳۰ طرح قابل انتخاب جایگزین می‌کند. نه پنل است، نه
پوسته‌ای برای بخش مدیریت، و نه کلاینت — فقط چیزی را تغییر می‌دهد که مشترک شما می‌بیند.

به‌طور پیش‌فرض **کاملاً بی‌نام‌ونشان** است. نام سرویس، لینک پشتیبانی و لوگوی شما متعلق به
خودتان است، در به‌روزرسانی‌ها باقی می‌ماند، و نام خود رو-تمپلیت هیچ‌جای صفحهٔ ارائه‌شده دیده
نمی‌شود مگر خودتان آن را وارد کنید.

## خلاصهٔ نصب

```bash
bash <(curl -fsSL https://github.com/iitzSeriZdev/Row-Template/releases/latest/download/install.sh)
```

سپس مدیریت نصب با دستور `row-template`:

```bash
row-template verify
```

## دربارهٔ این مستندات

این مستندات به **انگلیسی، فارسی و عربی** در دسترس است. انگلیسی مرجع اصلی است؛ فارسی و
عربی درجه‌یک‌اند و چیدمان راست‌به‌چپ دارند، نه بازتابی پس از ساخت.

هر چیزی که از نصب‌کننده یا خط فرمان نقل شود، در همهٔ زبان‌ها **انگلیسی** می‌ماند، چون
خروجی واقعی ابزار همان است.
