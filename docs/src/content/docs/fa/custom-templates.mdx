Gold-Template شامل ۱۷ طرح core قفل‌شده و ۱۳ طرح سفارشی downstream است. افزودن طرح جدید ممکن است و قراردادی که باید
برآورده شود نوشته شده است — نه اینکه با شکستن چیزها کشف شود.

> **وضعیت:** tier سفارشی در محصول واقعی استفاده می‌شود. GoldApp اکنون ۱۳ طرح سفارشی
> از `gold` تا `dashboardpro` را کنار ۱۷ طرح core قفل‌شده عرضه می‌کند. این صفحه قرارداد
> لازم برای طرح‌های سفارشی بعدی را مشخص می‌کند.

## مدل دو سطحی

هر تمپلیت به یک سطح تعلق دارد:

| | `core` | `custom` |
|---|---|---|
| همراه نسخه عرضه می‌شود | بله | اختیاری |
| **قفل‌شده با checksum** | **بله** | **نه** |
| تغییرپذیری | فقط با یک به‌روزرسانی صریح قفل | آزادانه، توسط سازندهٔ آن |
| ملزم به قرارداد زمان اجرا | بله | **بله** |
| ملزم به قرارداد دسترس‌پذیری | بله | **بله** |

> **تنها تفاوت میان یک تمپلیت اصلی و یک تمپلیت سفارشی، قفل checksum است.** همهٔ الزامات
> زمان اجرا، دسترس‌پذیری و فایل خروجی یکسان‌اند.

تمپلیت سفارشی، تمپلیت درجه‌دو نیست. تمپلیتی است که هیچ‌کس قول نداده تغییرش ندهد.

## قرارداد زمان اجرا

یک تمپلیت سفارشی باید همهٔ این‌ها را برآورده کند:

- **۷۹ قلاب لازم**، هرکدام دقیقاً یک‌بار.
- عبور از `validateLayout()`.
- **زمان اجرای راه‌انداز** بایت‌به‌بایت یکسان با Row.
- **زمان اجرای برنامه** بایت‌به‌بایت یکسان با Row.
- **جزیرهٔ زبان‌ها** بایت‌به‌بایت یکسان.
- **دقیقاً سه تگ `<script>`** — راه‌انداز، جزیرهٔ زبان‌ها، برنامه.
- **بدون fork کردن runtime مشترک برنامه.** enhancement کوچک مخصوص طرح فقط وقتی مجاز است
  که کاملاً به همان طرح محدود باشد و تست build/runtime مستقل داشته باشد.

## مالکیت چیدمان

هر تمپلیت پوشه و DOM خودش را دارد:

```
src/templates/<id>/
├── layout.html
├── tokens.css
├── base.css
├── layout.css
├── components.css
└── rtl.css
```

- طرح سفارشی می‌تواند از contract تست‌شدهٔ یک layout/core استفاده کند، به شرط اینکه reuse
  صریح، مستند و تست‌شده باشد.
- runtime برنامه مشترک می‌ماند و overrideهای بصری باید downstream و scoped باشند.

## دسترس‌پذیری

هر عنصر تعاملی باید **۴۴ پیکسل** را رد کند، بدون استثنا — دکمه‌ها، لینک‌ها، زبانه‌ها،
کنترل‌های دیالوگ و آیتم‌های فهرست کشویی.

## قواعد فایل خروجی

- یک فایل **مستقل**.
- **بدون منبع بیرونی، بدون قلم خارجی، بدون وابستگی به شبکه.** دارایی‌ها هنگام ساخت درون‌ریز
  می‌شوند.
- **خروجی قطعی و تکرارپذیر.**
- در محدودهٔ سخت **۲۸۰ KiB (۲۸۶٬۷۲۰ بایت)**.

## راست‌به‌چپ

فارسی و عربی درجه‌یک‌اند. استفاده از ویژگی‌های منطقی در سراسر کار، `dir="auto"` روی
محتوایی که جهت‌اش واقعاً نامعلوم است، و بدون سرریز افقی در ۳۲۰، ۳۹۰، ۴۳۰ یا ۱۴۴۰.

## برندسازی

یک تمپلیت نباید برند اشتراک را بازنویسی کند. برند متعلق به اشتراک است، نه به طرح.
